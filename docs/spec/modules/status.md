# Модуль: Status
- Источник в ТЗ: строки 66–67
- Зависит от: Subscriber (opt-in, opt-out, charging suspend)
- Используется в: приёмка F5, рубрика корректности потоков
- Статус: draft

## Назначение

Отдать текущее состояние подписчика так, как его видит наш сервис.

## Сущности и статусы

Состояние Subscriber: как минимум ACTIVE и INACTIVE. Suspend — см. Q4. В ответ входит «your view», не вид Platform.

## Требования

- REQ-STA-001: An endpoint that returns a subscriber's current state (your view).

Состав JSON и поведение для неизвестного абонента в ТЗ не заданы. Путь после Q6: `GET /subscribers/{subscriberId}`, без UI.

## Бизнес-правила и валидации

Нет дополнительных правил, кроме возврата текущего состояния.

Запрос «был ли MSISDN X списан сегодня и какой reference» — это аудит списаний, не этот эндпоинт. См. REQ-AUD-002 в `03-cross-cutting.md`.

## Интеграции

Нет.

## Права доступа

Не заданы. Real auth вне скоупа (REQ-OVW-006).

## Нефункциональные требования модуля

Нет отдельных НФТ.
