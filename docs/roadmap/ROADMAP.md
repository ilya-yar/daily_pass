## Post-MVP (не удалено, в задачи MVP не входит)

- Расписание job. Ручной запуск закрывает формулировку «scheduled **or** manually triggerable» (REQ-CHG-001). См. A-MANUAL-JOB.
- Real auth/SSO, multi-currency, USSD, DLR, Query Balance, production infra, pixel-perfect UI (REQ-OVW-006) — не строим и прямо говорим об этом в DECISIONS.md.
- Возобновление подписчика из suspend. В ТЗ такого сценария нет.
- Содержательная реакция на webhook `PENDING` и `CHARGE` сверх ответа `S1000` и записи события. Пока это Q5, не функция.
- Обязательный возврат `E1318` моком. Сервис код обработать обязан; мок — нет (A-MOCK-E1318).
